# ระบบเข้าสู่ระบบและ Role

ระบบใช้บัญชีอีเมลและรหัสผ่าน ไม่มีการสมัครบัญชีด้วยตนเอง ผู้ใช้พิมพ์ชื่อบัญชีได้โดยไม่ต้องใส่ `@obn.com` (เช่น `owner`) หรือใส่อีเมลเต็มก็ได้ ผู้ดูแลสร้างบัญชีและเลือกระดับสิทธิ์ที่หน้า `/admin/users` ได้ ส่วนหน้า `/admin/roles` ใช้ปรับสิทธิ์ของแต่ละ Role

## เริ่มใช้งานครั้งแรก

1. คัดลอกค่าที่จำเป็นจาก `.env.example` ไปยัง `.env` และตั้ง `BETTER_AUTH_SECRET` เป็นค่าสุ่มที่ยาวอย่างน้อย 32 bytes
2. ใช้ `npm run db:deploy` เพื่อเพิ่มตารางบัญชีและ Role ในฐานข้อมูลปัจจุบัน
3. ใช้ `npm run auth:create-admin -- --email admin@example.com --name "ผู้ดูแลระบบ" --role owner` แล้วตั้งรหัสผ่านตามขั้นตอนของคำสั่ง (อย่างน้อย 8 ตัวอักษร)
4. เปิด `/login` และเข้าสู่ระบบด้วยบัญชีเจ้าของระบบ จากนั้นสร้างบัญชีพนักงานใน `/admin/users`

Role มาตรฐานมี เจ้าของระบบ, ผู้ดูแลระบบ, ผู้จัดการ, พนักงาน และผู้ดูข้อมูล การตรวจสิทธิ์ทำที่ API ทุกคำขอด้วย จึงไม่อาศัยการซ่อนเมนูในหน้าจอเพียงอย่างเดียว
