# รูปแบบการบันทึกบัญชีทรัพย์สิน — OBN Wealth

## วัตถุประสงค์

ออกแบบทะเบียนทรัพย์สินและรายการบัญชีสำหรับ OBN Co., Ltd. ให้ติดตามได้ว่าใครเป็นเจ้าของ อยู่ที่บริษัท/สาขาใด ซื้อมาอย่างไร ใช้บัญชีใด คิดค่าเสื่อมราคาเท่าไร และมูลค่าคงเหลือเท่าใด โดยยังดูราคาประเมินเพื่อ Net Worth แยกได้

ทะเบียนนี้ต้องรองรับบริษัทในกลุ่มและสำนักงานใหญ่/สาขาเป็นมิติแยกกัน ข้อมูล Dashboard รวมได้ แต่รายการบันทึกต้องมีบริษัทเจ้าของและสถานที่ใช้งานกำกับทุกครั้ง

## หลักการออกแบบ

1. **หนึ่งทรัพย์สินมีรหัสถาวร** เช่น `OBN-AST-000001`; เมื่อย้ายที่ตั้ง เปลี่ยนผู้ดูแล ปรับราคา หรือจำหน่าย ให้เก็บเป็นเหตุการณ์/ประวัติ ไม่สร้างรหัสใหม่
2. **แยกทะเบียนทรัพย์สินจากสมุดบัญชี** ทะเบียนเก็บรายละเอียดเฉพาะทรัพย์สิน ส่วนการซื้อ ค่าเสื่อมราคา ด้อยค่า ปรับปรุงราคา และจำหน่าย ต้องสร้างรายการบัญชีที่เดบิตเท่ากับเครดิต
3. **แยกฐานมูลค่า 3 แบบ** ได้แก่ ราคาทุนและมูลค่าตามบัญชี, ฐานภาษี, และราคาประเมินเพื่อบริหาร Net Worth
4. **ห้ามบันทึกราคาตลาดเข้าเป็นกำไรหรือเพิ่มมูลค่าบัญชีโดยอัตโนมัติ** การตีราคาใหม่ต้องผ่านนโยบายบัญชีและการอนุมัติก่อน
5. บันทึกผู้ทำรายการ เอกสารอ้างอิง วันที่มีผล ผู้อนุมัติ และประวัติการแก้ไข

### C. การลงบัญชีและค่าเสื่อมราคา

แสดงเฉพาะสินทรัพย์ที่ต้องบันทึกในทะเบียนสินทรัพย์ถาวร; ช่องบัญชีให้เลือกจากผังบัญชีจริงของบริษัท

| ช่องข้อมูล | รูปแบบ/ข้อกำหนด |
|---|---|
| บัญชีสินทรัพย์ | บัญชีแยกประเภทสำหรับประเภททรัพย์สิน |
| บัญชีค่าเสื่อมราคาสะสม | บัญชีหักสินทรัพย์ |
| บัญชีค่าเสื่อมราคา | ค่าใช้จ่าย หรือบัญชีต้นทุนงานตามหน่วยใช้งาน |
| มูลค่าคงเหลือ | จำนวนเงินที่คาดว่าจะได้รับเมื่อสิ้นอายุใช้งาน |

## รูปแบบรายการบัญชี

ทุกรายการประกอบด้วย: วันที่รายการ, เลขที่รายการ, ประเภทเหตุการณ์, บริษัท, สาขา/หน่วยงาน, รหัสทรัพย์สิน, คู่ค้า, บัญชีเดบิต, บัญชีเครดิต, จำนวนเงิน, ภาษี, เอกสารอ้างอิง, คำอธิบาย, ผู้บันทึก, ผู้อนุมัติ และสถานะร่าง/รออนุมัติ/ผ่านรายการ/กลับรายการ

ตัวอย่างซื้ออุปกรณ์ 100,000 บาท และภาษีซื้อ 7,000 บาทที่ขอคืนได้:

| เดบิต | เครดิต | จำนวน |
|---|---|---:|
| อุปกรณ์สำนักงาน |  | 100,000 |
| ภาษีซื้อ |  | 7,000 |
|  | ธนาคาร/เจ้าหนี้ | 107,000 |

ตัวอย่างค่าเสื่อมรายเดือน: เดบิตค่าเสื่อมราคา และเครดิตค่าเสื่อมราคาสะสมตามตารางที่ผ่านอนุมัติ ระบบต้องตรวจว่าเดบิตรวมเท่ากับเครดิตรวมก่อนผ่านรายการ

## หน้าจอและขั้นตอนใช้งาน

1. จาก `/dashboard` เลือก **ทรัพย์สินถือครอง** หรือ **เพิ่มทรัพย์สิน**
2. เปิดฟอร์มหน้าเดียว โดยเริ่มจากบริษัท/สาขา ประเภท ชื่อ วิธีได้มา และต้นทุน
3. เมื่อเลือกประเภท ระบบแสดงช่องเฉพาะประเภทและช่องบัญชีที่เกี่ยวข้อง
4. ผู้บันทึกแนบเอกสารและบันทึกเป็น **ร่าง**; ระบบตรวจช่องบังคับและผลรวมเดบิต/เครดิต
5. ส่งให้ผู้มีสิทธิ์ตรวจ/อนุมัติ; เมื่อผ่านอนุมัติจึงสร้างรายการบัญชีและรหัสรายการอ้างอิง
6. ระบบแสดงทะเบียน, มูลค่าตามบัญชี, ฐานภาษี และราคาประเมิน Net Worth แยกมุมมองกัน
7. ย้าย/ปรับปรุง/ด้อยค่า/จำหน่ายผ่านรายการเหตุการณ์ใหม่ ไม่ลบประวัติเดิม

## แยกประเภทงานที่ควรอยู่ในโมดูล

- **ทะเบียนสินทรัพย์ถาวร:** อาคาร รถ เครื่องจักร และอุปกรณ์ พร้อมค่าเสื่อมราคา
- **พอร์ตการลงทุน:** หุ้น กองทุน และทอง พร้อมจำนวนหน่วย ต้นทุน และราคาตลาด; กำหนดการรับรู้บัญชีตามประเภทและมาตรฐานที่เกี่ยวข้อง
- **เงินสดและเงินฝาก:** ดึงยอดจากบัญชีเงินสด/ธนาคารเป็นแหล่งข้อมูลหลัก ไม่สร้างยอดซ้ำในทะเบียนสินทรัพย์
- **สินทรัพย์ระหว่างก่อสร้าง:** ติดตามต้นทุนโครงการก่อนโอนเป็นสินทรัพย์พร้อมใช้งาน
- **หนี้สิน:** บันทึกแยกจากสินทรัพย์; บ้าน/รถบันทึกมูลค่าทรัพย์สินเต็มตามเกณฑ์และยอดหนี้คงเหลือแยกในทะเบียนหนี้สิน

## รายงานที่ต้องได้

- ทะเบียนสินทรัพย์แยกบริษัท สาขา หมวด และสถานะ
- รายงานต้นทุน ค่าเสื่อมราคาสะสม ด้อยค่า และมูลค่าตามบัญชี ณ วันที่เลือก
- ตารางค่าเสื่อมทางบัญชีและตารางภาษีแยกกัน
- รายงานราคาประเมินและ Net Worth พร้อมวันที่/แหล่งราคา
- รายงานประวัติการซื้อ ย้าย ปรับปรุง จำหน่าย และผู้อนุมัติ
- รายงานกระทบยอดทะเบียนสินทรัพย์กับบัญชีแยกประเภท

## เงื่อนไขก่อนเปิดใช้จริง

- ผู้ทำบัญชียืนยันผังบัญชี วิธีรับรู้ต้นทุน เกณฑ์เริ่มคิดค่าเสื่อม อายุใช้งาน มูลค่าคงเหลือ และ threshold การตั้งเป็นสินทรัพย์
- ยืนยันนโยบายแยกมาตรฐานบัญชีและภาษี รวมถึงมาตรฐานที่กิจการใช้
- กำหนดสิทธิ์ผู้บันทึก/ผู้อนุมัติ และห้ามผู้ใช้อนุมัติรายการของตนเองหากนโยบายกำหนด
- ตรวจบัญชีเปิดต้นงวดและวิธีนำเข้ายอดยกมา เพื่อป้องกันบันทึกสินทรัพย์ซ้ำกับสมุดบัญชีเดิม

## หลักอ้างอิง

- [มาตรฐานการบัญชี ฉบับที่ 16 เรื่อง ที่ดิน อาคารและอุปกรณ์ — สภาวิชาชีพบัญชี](https://eservice.tfac.or.th/files/accounting_std_document/TAS_16_revised_2566.pdf)
- [เงื่อนไขการคำนวณกำไรสุทธิตามมาตรา 65 ทวิ — กรมสรรพากร](https://www.rd.go.th/828.html)

เอกสารนี้เป็นแบบออกแบบระบบ ไม่ใช่การวินิจฉัยทางบัญชีหรือภาษี การตั้งค่าที่จะผ่านรายการจริงต้องให้ผู้ทำบัญชีของแต่ละบริษัทตรวจรับก่อน
