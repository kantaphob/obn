## เปิดการส่งอัตโนมัติ (ทำครั้งเดียว)

1. เปิด https://console.cloud.google.com/ แล้วสร้างหรือเลือกโปรเจกต์
2. ไป APIs & Services → Library ค้นหา **Google Sheets API** แล้วกด **Enable**
3. ไป IAM & Admin → Service Accounts → **Create service account** ตั้งชื่อ `loan-sheet-sync` แล้วสร้าง โดยไม่ต้องให้ Project Owner/Editor
4. เปิดบัญชีที่สร้าง → Keys → Add key → Create new key → **JSON** แล้วดาวน์โหลดไฟล์
5. คัดลอกอีเมลของบัญชีนั้น (ลงท้าย `iam.gserviceaccount.com`) เปิดชีต → แชร์ → เพิ่มอีเมลนี้เป็น **ผู้แก้ไข** ไม่ต้องเปิดไฟล์เป็นสาธารณะ
6. เก็บ JSON นอก `public/` เช่น `/Users/ohmz/Documents/obn/secrets/google-sheets.json` แล้วตั้งใน `.env.local`:

```dotenv
GOOGLE_SHEETS_SPREADSHEET_ID="1xMm0QVElj7hrH69QhGC9Kb3KsLR_KA7mXZemBBVnFug"
GOOGLE_SHEETS_TAB_NAME="ชีต1"
GOOGLE_SHEETS_SERVICE_ACCOUNT_FILE="/Users/ohmz/Documents/obn/secrets/google-sheets.json"
```

7. เริ่มเซิร์ฟเวอร์ใหม่ เปิดหน้าสัญญากู้ แล้วกด **ซิงก์ตอนนี้** ครั้งแรก

หากไม่สะดวกตั้งไฟล์ ให้แจ้งเฉพาะตำแหน่งไฟล์ JSON ที่ดาวน์โหลด ไม่ต้องวางเนื้อหาไฟล์ในแชต

## การทำงาน

- หลังสร้าง แก้ไขเงื่อนไข จ่ายเงินตามสัญญา หรือแก้ไขข้อมูลผู้กู้ ระบบส่งรายการสัญญาที่บันทึกทั้งหมดไปยังชีตหลังตอบกลับผู้ใช้แล้ว ไม่รวมร่างที่ยังอยู่ใน LoanContractDraft
- เขียน A:J เป็นสำเนาปัจจุบัน เรียงตามเลขสัญญา จึงไม่เกิดแถวซ้ำเมื่อแก้ไขหรือกดซิงก์ซ้ำ
- คอลัมน์ A:J เป็นข้อมูลจากระบบ หากแก้เองในชีตจะถูกแทนด้วยข้อมูลระบบเมื่อซิงก์ครั้งถัดไป ใช้แท็บอื่นสำหรับบันทึกเพิ่มเติม
- หัวตารางต้องตรงรูปแบบ หากไม่ตรง ระบบหยุดแทนการเขียนทับ
- หาก Google ไม่ตอบรับ สัญญาในระบบยังบันทึกสำเร็จ สถานะซิงก์เก็บใน `storage/integrations/google-sheets-status.json`
- ลองใหม่ด้วย “ซิงก์ตอนนี้” หรือเมื่อบันทึก/แก้ไขสัญญาครั้งถัดไป ระบบจะส่งภาพรวมล่าสุด รวมรายการที่เคยส่งไม่สำเร็จ ไม่มีการตั้งเวลาลองซ้ำเอง
- การซิงก์อัตโนมัติยังไม่เปิดจนกว่าจะตั้ง Service Account และสิทธิ์แชร์ครบ การส่งข้อมูลผ่านแชตเป็นการส่งครั้งเดียว
- ปัจจุบันใช้คิวในโปรเซส เหมาะกับเซิร์ฟเวอร์เดียวของโปรเจกต์นี้ หากเปลี่ยนเป็นหลายอินสแตนซ์ต้องเพิ่มคิวหรือ lock กลางก่อนใช้งาน

อ้างอิง: https://developers.google.com/workspace/guides/create-credentials และ https://docs.cloud.google.com/iam/docs/keys-create-delete
